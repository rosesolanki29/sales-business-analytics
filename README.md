
# 📊 Sales & Business Analytics Dashboard

## 📌 Project Overview

This project is an interactive **Sales & Business Analytics Dashboard** developed using **Microsoft Power BI**.

The dashboard transforms raw sales and order data into meaningful business insights by analyzing **revenue, profit, cost, units sold, product performance, regional performance, sales channels, and order trends**.

The goal is to provide a centralized view of business performance and support **data-driven decision-making**.

---

## 🎯 Project Objectives

* Analyze overall sales, revenue, cost, and profitability.
* Monitor sales performance across different countries and regions.
* Identify high-performing and low-performing product categories.
* Compare different sales channels.
* Analyze order and sales trends over time.
* Provide actionable insights for business decision-making.

---

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development & visualization
* **DAX** – KPI and calculated measure development
* **Data Analysis** – Business and performance analysis
* **Data Visualization** – Interactive charts, KPIs and filters

## 📂 Dataset

The dataset contains sales and order-level information.

### Dataset Columns

| Category            | Columns                                                             |
| ------------------- | ------------------------------------------------------------------- |
| Business Dimensions | Country, Region, Item Type, Rep Name, Sales Channel, Order Priority |
| Dates               | Order Date, Ship Date                                               |
| Identifier          | Order ID                                                            |
| Financial Metrics   | Total Cost, Total Profit, Total Revenue, Unit Cost, Unit Price      |
| Sales Volume        | Units Sold                                                          |
